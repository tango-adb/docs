# UHID

UHID (User-space I/O driver support for HID subsystem) lets Scrcpy create virtual Human Interface Devices on the Android device.

- [UHID manager](./manager.mdx): Create devices and manage their lifetime.
- [UHID device](./device.mdx): Send input reports and inspect device properties.
- [UHID output stream](./output-stream.mdx): Read reports sent back by a virtual device.
- [UHID control messages](../control/uhid.mdx): Use the low-level protocol messages directly.
