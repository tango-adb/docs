# sendCodecMeta

{/* Source: libraries/scrcpy/src/2_0/impl/init.ts | Commit: f65f90fe93a5c18bcfe11a93edd49515a4cea3ae */}


:::info

Added in Scrcpy 2.0

:::

:::danger

Deprecated in Scrcpy 4.0

Use [`sendStreamMeta`](../v4.0/send-stream-meta.mdx) instead.

:::

- **Type**: `boolean`
- **Default value**: `true`

Controls whether codec metadata should be sent at the start of the video and audio streams.

## Changelog

### v2.0

When `true`, server will send codec metadata after device name (controlled by [`sendDeviceMeta`](../v1.22/send-device-meta.mdx) option). Codec metadata includes:

- Codec ID (4 bytes)
- Initial video width (2 bytes)
- Initial video height (2 bytes)

### v4.0

- Replaced by [`sendStreamMeta`](../v4.0/send-stream-meta.mdx).

## Related options

- [`videoCodec`](./video-codec.mdx): Specifies the video codec to use
- [`audioCodec`](./audio-codec.mdx): Specifies the audio codec to use
- [`sendDeviceMeta`](../v1.22/send-device-meta.mdx): Controls whether device name is sent
- [`sendStreamMeta`](../v4.0/send-stream-meta.mdx): Replacement option in v4.0+

## Example

```ts transpile
import { ScrcpyOptions2_0 } from "@yume-chan/scrcpy";

const options = new ScrcpyOptions2_0({
  sendCodecMeta: false, // Disable sending codec metadata
});
```
