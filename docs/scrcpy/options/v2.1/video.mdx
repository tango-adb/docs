# video

{/* Source: libraries/scrcpy/src/2_1/impl/init.ts | Commit: f65f90fe93a5c18bcfe11a93edd49515a4cea3ae */}


:::info

Added in Scrcpy 2.1

:::

* **Type**: `boolean`
* **Default value**: `true`

Disables the [video socket](../../connect-server.mdx#sockets), allowing an audio only mode.

Control messages that requires video size won't work with video disabled.

## Related options

- [`audio`](../v2.0/audio.mdx): Controls whether the audio socket is enabled
- [`control`](../v1.15/control.mdx): Controls whether the control socket is enabled

## Example

```ts transpile
import { ScrcpyOptions2_1 } from "@yume-chan/scrcpy";

const options = new ScrcpyOptions2_1({
    video: false, // Disable video socket for audio-only mode
});
```
